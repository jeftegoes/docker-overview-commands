# 1. Local deployment

- Perfect for testing or getting started with Kafka
  `curl -L https://lenses.io/preview -o docker-compose.yml && ACCEPT_EULA=true docker compose up -d --wait && echo "Lenses.io is running on http://localhost:9991"`
  1. Run the docker command
  2. Open the Lenses HQ at http://localhost:9991
  3. Sign in with admin / admin
  4. Verify with your email, and activate Lenses
- See detailed instructions for the deployment and RAM/VM requirements in [Lenses Docs](https://docs.lenses.io/latest/getting-started/quickstart)
